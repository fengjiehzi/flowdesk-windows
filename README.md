# Windows 灵动岛

一个常驻 Windows 桌面顶部的状态与快捷控制中心。把鼠标移到屏幕顶部即可唤出灵动岛，用它查看时间、启动常用应用或网站，并自定义顶部触发器的外观与交互。

## 功能

- 顶部触发：鼠标移到屏幕顶部显示触发器，点击或下拉进入灵动岛。
- 快捷入口：最多保存 8 个应用或网站，支持自动扫描、选择 `.exe` / `.lnk`、改名、排序和删除。
- 流云创作器：内置经典、流体、界面、游戏、二次元、自然 6 类共 31 款动效。
- 自由定制：调整颜色、粒子、速度、尺寸、曲率、对称性、触发范围和隐藏延迟，并保存最多 32 个作品。
- 托盘控制：快速显示、隐藏、切换 8 种主题、打开创作器或退出程序。
- 多显示器支持：灵动岛会显示在当前操作的屏幕上，并保持窗口置顶。

## 安装与运行

当前仓库提供源码。需要 Windows 10/11、Node.js 20.19 或更高版本。

```powershell
git clone https://github.com/fengjiehzi/vibe-flow.git
cd vibe-flow
npm ci
npm run dev
```

生成 Windows 安装包：

```powershell
npm run pack:win
```

安装包会生成在 `release/` 目录。

## 使用说明

### 1. 添加快捷入口

首次启动会打开“快捷入口管理器”：

1. 在“选择应用”中扫描并勾选已安装程序，然后点击“添加所选”。
2. 也可以点击“选择 `.exe` / `.lnk`”手动选择程序。
3. 在“添加网站”中填写名称和网址；打开时会使用 Windows 默认浏览器。
4. 在“已选择”中拖拽排序、修改名称或删除入口。
5. 点击“完成”保存。以后可在灵动岛面板中点击“管理”再次打开。

### 2. 唤出和操作灵动岛

1. 将鼠标移到当前屏幕顶部中央，等待触发器出现。
2. 点击触发器或向下拖动，显示紧凑时间胶囊。
3. 点击时间胶囊，展开快捷入口面板。
4. 点击应用或网站即可打开；启动后灵动岛会自动隐藏。
5. 横向拖动顶部触发器可以改变它的位置。
6. 点击灵动岛以外区域会隐藏界面，再次触碰屏幕顶部即可唤出。

### 3. 自定义外观

在展开面板中点击“创作”，或右键托盘图标选择“流云创作器”：

1. 从左侧选择动效分类或载入已保存作品。
2. 选择预设后，在右侧调整颜色、几何、动态和交互参数。
3. 输入作品名称，点击“保存”或“另存为”。
4. 已保存作品支持载入、重命名、复制和删除。

主题可通过托盘图标的“主题”菜单切换。

### 4. 托盘菜单

程序关闭普通窗口后仍会驻留托盘。右键任务栏托盘中的“Windows 灵动岛”图标，可以：

- 显示或隐藏灵动岛；
- 切换主题；
- 打开流云创作器；
- 完全退出程序。
