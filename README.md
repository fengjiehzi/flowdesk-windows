# Windows 灵动岛

一个常驻 Windows 桌面顶部的状态与快捷控制中心。通过全局快捷键或托盘唤出灵动岛，用它查看时间和系统通知、启动常用应用或网站，并按需归档剪贴板内容。

## 功能

- 快速唤出：在任意程序中按 `Ctrl+Alt+Space`，或点击托盘图标显示紧凑岛，不占用屏幕顶部操作区域。
- 快捷入口：最多保存 8 个应用或网站，支持自动扫描、选择 `.exe` / `.lnk`、改名、排序和删除。
- 桌面整理：内置 SmartDeskBox 原生模块，在桌面显示应用与文件分类盒子，支持原生文件菜单、拖放、布局记忆、管理与搜索、手动分类、沙盒备份及可选 AI 识别。
- 通知中心：新通知会让灵动岛自动变为通知胶囊，并可选捕获微信、飞书桌面弹窗；通知历史仅保存在本次运行内。
- 剪贴板归档：选择启用后，将复制的文字、图片和媒体文件保存到本地文档目录。
- FLUX 流体材质：以原生 WebGL 统一覆盖紧凑岛、通知胶囊和展开面板顶部；不支持 WebGL 时自动使用 CSS 三色渐变。
- 流云创作器：保留经典、流体、界面、游戏、二次元、自然 6 类共 31 款配色预设，并支持紧凑岛、通知胶囊、面板顶部三种比例预览。
- 自由定制：调整三种颜色、流速、噪声尺度、Warp 强度、色彩密度和交互响应，并保存最多 32 个方案。
- 托盘控制：快速显示、隐藏、切换 8 种主题、打开创作器或退出程序。
- 多显示器支持：灵动岛会显示在当前操作的屏幕上，并保持窗口置顶。

## 安装与运行

### 直接安装

前往 [Releases](https://github.com/fengjiehzi/vibe-flow/releases/latest) 下载最新版 `Windows-Dynamic-Island-*-Setup.exe`，双击并按向导完成安装。

> 发布构建强制使用代码签名证书。新证书或信誉不足的证书仍可能触发 Windows SmartScreen，请只从本仓库 Releases 下载，并核对对应版本发布说明中的 SHA-256。

### 从源码运行

基础开发需要 Windows 10/11、Node.js 20.19 或更高版本。

```powershell
git clone https://github.com/fengjiehzi/vibe-flow.git
cd vibe-flow
npm ci
npm run dev
```

首次开发桌面整理功能，另需 .NET 10 SDK，执行 `npm run desktop:build` 生成内置原生模块。该命令仅发布桌面整理模块；正式安装包包含自包含模块，用户无需另装 .NET。

在灵动岛展开面板顶部的“桌面整理”中启用桌面盒子、打开“分类与备份”或设置；托盘也有相同入口。关闭管理窗口只隐藏窗口，退出灵动岛时会退出桌面模块并恢复系统桌面。启用状态会自动保存，下次启动灵动岛时恢复；“恢复系统桌面”会停用盒子。

桌面整理数据保存在灵动岛用户数据目录下的 `desktop-boxes` 中，与原 SmartDeskBox 项目隔离。分类和跨分类拖动不移动文件；原生菜单中的剪切、删除、重命名等操作作用于真实文件。AI 默认关闭，可在桌面整理设置中配置；备份只复制至模块沙盒，不改变原文件。

如需调试 Windows 通知，另需安装 .NET 8 SDK、Windows 10 SDK 10.0.19041.0 或更高版本及 PowerShell 7，然后生成并注册开发包身份：

```powershell
npm run identity:dev
npm run dev
```

`identity:dev` 会为当前用户创建并信任自签名开发证书、注册稀疏 MSIX 包身份。

生成正式 Windows 安装包前，需要提供代码签名证书。`WIN_CSC_LINK` 支持证书文件路径、URL 或 Base64 内容：

```powershell
$env:WIN_CSC_LINK = 'C:\path\release-certificate.pfx'
$env:WIN_CSC_KEY_PASSWORD = 'certificate-password'
npm run pack:win
```

命令会签名原生桥接、MSIX 包身份和 NSIS 安装包，产物位于 `release/` 目录。

## 使用说明

### 1. 添加快捷入口

首次启动会打开“快捷入口管理器”：

1. 在“选择应用”中扫描并勾选已安装程序，然后点击“添加所选”。
2. 也可以点击“选择 `.exe` / `.lnk`”手动选择程序。
3. 在“添加网站”中填写名称和网址；打开时会使用 Windows 默认浏览器。
4. 在“已选择”中拖拽排序、修改名称或删除入口。
5. 点击“完成”保存。以后可在灵动岛面板中点击“管理”再次打开。

### 2. 唤出和操作灵动岛

1. 在任意程序中按 `Ctrl+Alt+Space`，或点击托盘图标，显示当前屏幕的紧凑时间胶囊。
2. 点击时间胶囊，展开快捷入口面板。
3. 点击应用或网站即可打开；启动后灵动岛会自动隐藏。
4. 鼠标进入灵动岛后再离开，界面会按设置的隐藏延迟自动收起。

### 3. 自定义外观

在展开面板中点击“创作”，或右键托盘图标选择“流云创作器”：

1. 从左侧选择 FLUX 配色分类，或从“方案目录”载入已保存方案。
2. 选择预设后，在右侧调整三色、流速、噪声、Warp、密度和交互参数，并在主画布切换三种灵动岛比例。
3. 点击“新建”创建方案，输入方案名称后点击“保存”。
4. 载入已有方案后可继续修改，点击“保存”会直接更新原方案。
5. 已保存方案支持载入、重命名、复制和删除。

主题可通过托盘图标的“主题”菜单切换。

隐藏延迟位于托盘菜单的“设置”窗口。

### 4. 系统通知

1. 从托盘菜单打开“设置”，启用“监听通知中心”并允许 Windows 通知访问。
2. 新通知会以带应用图标、标题和摘要的灵动岛胶囊出现；点击胶囊可展开通知列表，也可按来源屏蔽通知。
3. “微信/飞书桌面弹窗”是可选功能，只在启用后读取新出现的桌面弹窗。
4. 灵动岛仅在内存中保存最近 24 小时、最多 100 组通知，退出程序后清空。

### 5. 剪贴板归档

在“设置”中启用“自动保存复制内容”后，文字、图片和媒体文件会保存到 `文档\Windows灵动岛\剪贴板记录`。剪贴板可能包含敏感信息，请仅在需要时启用。

### 6. 托盘菜单

程序关闭普通窗口后仍会驻留托盘。右键任务栏托盘中的“Windows 灵动岛”图标，可以：

- 显示或隐藏灵动岛；
- 切换主题；
- 打开流云创作器；
- 完全退出程序。

## 项目结构

```text
src/
├─ main/       Electron 主进程与快捷入口管理
├─ preload/    安全的渲染进程桥接 API
├─ renderer/   React 界面与动效
└─ shared/     设置、状态机、流云预设和数据校验
resources/     应用图标
native/        Windows 通知与剪贴板原生桥接
build/         MSIX 包身份与 NSIS 安装配置
scripts/       Windows 构建脚本
```
